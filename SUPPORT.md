# Support

For normal bugs and feature requests, open a GitHub issue:

https://github.com/Midtown-Technology-Group/detour/issues

Before filing, include:

- `detour --version` if available, or the installed tag
- `detour config`
- operating system and shell
- the command that failed
- the expected and actual behavior

For security issues, do not open a public issue. See [SECURITY.md](SECURITY.md).
