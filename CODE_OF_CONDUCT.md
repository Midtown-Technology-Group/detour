# Code of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

## Our Pledge

We pledge to make participation in this project a respectful and harassment-free
experience for everyone.

## Expected Behavior

- Be kind and direct.
- Assume good intent, then clarify.
- Keep criticism focused on the work.
- Respect differing levels of experience and context.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or behavior.
- Publishing private information without permission.
- Sustained disruption of project work.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, and
other contributions that are not aligned with this code of conduct.

Report concerns to security@midtowntg.com.

For the full Contributor Covenant text, see:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/
